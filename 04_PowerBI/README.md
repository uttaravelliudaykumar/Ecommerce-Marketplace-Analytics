# Power BI Dashboard

This project contains six interactive Power BI dashboards:

1. Executive Overview
2. Sales & Revenue Analysis
3. Customer Analysis
4. Product & Seller Analysis
5. Delivery & Customer Satisfaction
6. Payment Analysis

The Power BI report was developed using PostgreSQL data and DAX measures.

The `.pbix` file is maintained separately and is not included in this GitHub repository.
Dashboard screenshots are available in `05_Reports/Dashboard_Screenshots/`.
